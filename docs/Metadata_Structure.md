# Metadata Files Structure

## Overview

The metadata files are organized by year (2015, 2018, 2022) and contain information about mouse mothers, pups, recording sessions, and experimental conditions.

## Generating Metadata Files

Metadata files can be generated automatically using the `generate_metadata.py` script:

**From local directory:**
```bash
python generate_metadata.py --local --source-dir dumps
```

**From Google Drive:**
```bash
python generate_metadata.py --drive --drive-folder-url "https://drive.google.com/drive/folders/YOUR_FOLDER_ID"
```

The script:
- Scans WAV files and extracts metadata from folder structure
- Loads sex information from Excel tables in year folders
- Generates files named: `Metadata Recording Mapping ({year}).xlsx` in `metadata/mapping/`
- Skips years that already have metadata files (incremental updates)

**📖 For detailed instructions:** See `GENERATE_METADATA_README.md`  
**☁️ For Google Drive setup:** See `GOOGLE_DRIVE_SETUP.md`

## File Organization

### `metadata/mapping/` (reference index)

Files named `Metadata Recording Mapping ({year}).xlsx` live in **`metadata/mapping/`**. They list all WAV-derived rows for that year (including a `Channel` column when applicable). The main pipeline **does not** scan this subfolder, so these files are **not** run automatically with `run_pipeline.py` — use the split `Data … For Syl Segmentation` workbooks at the top level of `metadata/` for batch processing.

### File Naming

**Old format (legacy):**
- `Data {year} For Syl Segmentation_{number}.xlsx` (e.g., `Data 2015 For Syl Segmentation_1.xlsx`)
- Files were split into multiple parts per year

**New format (generated by script):**
- `metadata/mapping/Metadata Recording Mapping ({year}).xlsx` (e.g., `metadata/mapping/Metadata Recording Mapping (2015).xlsx`)
- One file per year containing all records (reference index; not used by default pipeline discovery)

### 2015 Data
- **Old format**: 8 files (`Data 2015 For Syl Segmentation_1.xlsx` through `_8.xlsx`)
- **New format (reference index)**: `metadata/mapping/Metadata Recording Mapping (2015).xlsx` (single file)
- **Total records**: ~9,500 records
- **Why old files were split:**
  - Each file contained different groups of mothers and pups
  - Files were organized by experimental groups/batches
  - Some files contained only HT (Heterozygous) genotype, some only WT (Wild Type), some mixed
  - Different files covered different combinations of Days (6, 8, 10, 12)
  - Each file had a different range of Recording Numbers, suggesting separate processing periods

### 2018 Data
- **Old format**: 4 files (`Data 2018 For Syl Segmentation_1.xlsx` through `_4.xlsx`)
- **New format (reference index)**: `metadata/mapping/Metadata Recording Mapping (2018).xlsx` (single file)
- **Total records**: ~5,600 records
- Each file contains 1-2 unique mothers and 3-5 unique pups
- Minimal overlap between files

### 2022 Data
- **Old format**: 4 files (`Data 2022 For Syl Segmentation_2.xlsx` through `_4.xlsx`)
- **New format (reference index)**: `metadata/mapping/Metadata Recording Mapping (2022).xlsx` (single file)
- **Total records**: ~3,700 records
- Each file contains 2-3 unique mothers and 3-8 unique pups
- Some overlap between files (shared mothers)

## File Structure

Each metadata file contains the following columns:
- **Mother**: Mother mouse ID
- **Mother Genotype**: HT (Heterozygous) or WT (Wild Type)
- **Name**: Pup name/ID
- **Sex**: Mouse sex (loaded from Excel tables in year folders)
- **Offspring Genotype**: Pup genotype
- **Day**: Experimental day (typically 4, 6, 8, 10, or 12)
- **Session**: Recording session number (1, 2, etc.) - may be empty if only Channel is present
- **Channel**: Recording channel (1, 2, etc.) - extracted from `ch1`, `ch2` in path - may be empty if only Session is present
- **Recording Number**: Unique recording identifier (e.g., T0000001)

**Note:** The `generate_metadata.py` script automatically extracts these fields from WAV file paths and joins sex information from Excel tables.

## Key Observations

1. **Division by experimental groups**: Files are split by different mother/pup groups, not randomly
2. **Genotype separation**: Some files contain only one genotype (HT or WT), others are mixed
3. **Day coverage**: Most files cover multiple days (6, 8, 10, 12), but some are limited to specific days
4. **Recording ranges**: Each file has a distinct range of Recording Numbers, indicating separate processing batches

## Usage

The pipeline processes each metadata file independently:
- Loads metadata from `metadata/` directory
- Extracts year from filename (characters 5-9)
- Processes all recordings listed in the file
- Generates output files in `outputs/` directory
