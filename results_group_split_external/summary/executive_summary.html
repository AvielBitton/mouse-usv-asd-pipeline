Key Finding: Group Split Reveals True Generalization Gap

The random split achieves 71.3% accuracy with external data, but the group-aware split drops to 54.6% — barely above chance for an 18/82% class ratio. This confirms the model heavily relies on mouse-level features (mother genotype, strain) rather than learning acoustic patterns that generalize to unseen mice.

Analysis

Why Group Split Hurts More with External Data

  • Severe class imbalance in test set. The test set has only 18.2% HET (392 rows) vs 81.8% WT (1,767 rows). With so few HET samples, the model struggles to learn a reliable decision boundary.
  • mother_gen dominance. Feature importance shows mother_gen at 62.7%. In group split, entire litters go to one set — the model cannot memorize mother-level patterns from train and apply them to the same mother in test.
  • Correct labels make mother_gen less predictive. With correct genotyping, only ~42% of pups from HET mothers are actually HET (vs 61% in pipeline data). When this weaker signal is also split by group, it becomes nearly useless.

Conclusion

The combination of correct genotype labels + group-aware split produces the most honest evaluation of the model. At 54.6% accuracy with 0.41 HET F1, the current XGBoost approach does not generalize well to unseen mice.

Recommended next steps:

  • Address class imbalance (oversampling HET, SMOTE, or class weights in XGBoost)
  • Reduce reliance on mother_gen — explore acoustic-only feature sets
  • Collect more HET samples (currently only 27 mice)
  • Investigate alternative model architectures that better capture acoustic patterns
