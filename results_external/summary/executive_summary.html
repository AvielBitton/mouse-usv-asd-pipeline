Objective

Critical Finding: Pipeline Metadata Contains Genotype Labeling Error

Investigation revealed that the pipeline metadata files (metadata/Data 20xx For Syl Segmentation_N.xlsx) contain a systematic labeling error: all pups born to a HET mother were labeled HET, regardless of their actual individual genotype. Genetically, a HET × WT cross produces ~50% HET and ~50% WT offspring. The external file contains correct individual genotyping — pups from the same litter are properly differentiated as HET or WT.

Root Cause — 14 Mislabeled Mice

14 mice (17,045 syllable rows) are labeled HET in the pipeline but WT in the external file. These are all pups of HET mothers whose individual genotype is actually WT.

Example: Litter 13131J

Mother 13131J is HET. In the pipeline, all 4 pups were labeled HET. The external file correctly differentiates: 1A=WT, 2A=HET, 3A=WT, 4A=HET — consistent with the expected ~50/50 Mendelian ratio.

Impact on the Pipeline Model

  • The pipeline model was trained with 14 WT mice incorrectly labeled as HET (17,045 syllable rows with wrong labels).
  • This artificially inflated the HET class (42 mice instead of the correct 28) and made the HET/WT ratio appear more balanced (41/59%) than it truly is (24/76%).
  • The pipeline model’s higher accuracy was partly a result of learning incorrect labels, not of superior data quality.

Why Performance Dropped

  • Correct labels make the task harder. With correct genotyping, only 28 mice (24% of data) are truly HET. The pipeline’s inflated HET class (42 mice, 41%) made the classification artificially easier.
  • mother_gen signal weakened. mother_gen is the dominant feature (57% importance). In the pipeline, when mother=HET, 61% of pups are labeled HET. With correct labels, only 42% of pups from HET mothers are actually HET — the strongest signal becomes less discriminative.
  • Class imbalance. The true 24/76% HET/WT ratio is more imbalanced than the artificially inflated 41/59%, making the minority class harder to learn.

Conclusion

The external data is the correct ground truth. The pipeline metadata files contained a systematic labeling error: 14 WT mice were mislabeled as HET (all pups of HET mothers were assumed HET). The pipeline model’s higher accuracy was partly an artifact of training on incorrect labels.

The external data should be used as the sole data source going forward. The lower model performance reflects the true difficulty of the classification task with correct genotype labels and a naturally imbalanced HET/WT ratio (24/76%). Future work should focus on addressing this class imbalance (e.g. oversampling, class weights, or collecting more HET samples).
