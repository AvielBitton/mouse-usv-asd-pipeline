Objective

Compare the XGBoost ASD classifier across two data sources (pipeline vs. external) and two split strategies (random vs. group-aware), using corrected genotype labels in both sources. Determine whether the external data improves classification and how the model generalizes to unseen mice.

What the External Data Adds

  • +28 mice (all WT): 24 from 2024 that were missing from the pipeline (due to absent Sex metadata) and 4 additional mice from other years.
  • +3,566 feature rows (recordings): more data for training and evaluation.
  • Correct individual genotyping: the external file differentiates pups within the same litter (HET vs WT), while the original pipeline metadata labeled all pups from HET mothers as HET. This was corrected in both sources (14 mice relabeled).
  • Same HET mice: both sources now have 27 HET mice after correction. The external data only adds WT mice, so the HET/WT imbalance increases.

Genotype Correction Applied

Both data sources now use corrected genotype labels. 14 mice previously mislabeled as HET (inherited from HET mothers but actually WT) have been corrected to WT in the pipeline metadata, segmentation outputs, and the external file already had correct labels. All results below reflect the corrected data.

4. Why Pipeline Accuracy Dropped After Correction

Before the genotype correction, the pipeline model showed 82.9% accuracy (random split). After correction, it dropped to 66.6%. This is because:

  • 14 mice were moved from HET to WT, making the HET class smaller and harder to learn.
  • The mother_gen feature became less predictive: previously, HET mother strongly predicted HET pup (61%); now only ~31% of pups from HET mothers are HET.
  • The old “high accuracy” was partly learning incorrect labels.

5. Why Legacy (2015–2022) Still Outperforms All Corrected Models

Despite having only 7,322 rows (vs 9,515–13,081), the legacy model achieves 76% accuracy, beating all corrected configurations. Three factors explain this:

a) The 2023–2024 data dilutes the HET signal

2023–2024 added only 8 HET mice out of 46 total — predominantly WT. The model gained more examples of healthy mice but not more examples of the disease it’s trying to detect.

b) Over-reliance on mother_gen (~50% feature importance)

Both legacy and corrected models use mother_gen as their dominant feature (~46–50%). The model essentially asks “is the mother HET?” and predicts HET. But HET mothers produce ~50% HET and ~50% WT pups, so this strategy generates many false positives. Adding 2023–2024 data introduced more WT pups from HET mothers, amplifying this error:

c) More mice = more variability

The legacy dataset (65 mice, 3 years) is more homogeneous. Adding 46 mice from 2023–2024 introduces different recording conditions and mouse cohorts. With random split (same mouse in train & test), fewer mice means the model can more easily memorize individual patterns. The acoustic features (syllable frequencies, durations, distances) contribute only ~1–3% each and are not strong enough to generalize across the expanded, more variable dataset.

More Data Did Not Improve the Model

The legacy model (7,322 rows, 65 mice) outperforms all corrected configurations despite having less data. The 2023–2024 additions contributed 38 WT mice but only 8 HET mice, diluting the disease signal. Combined with the model’s ~50% reliance on mother_gen (which is only ~50% predictive for offspring genotype), adding more data increased false positives without improving HET detection.

External Data Is the Best Corrected Option

Among the corrected configurations, external data with random split performs best (70.7% accuracy, 0.73 weighted F1), narrowing the gap with legacy. It provides correct genotyping, more mice (115 vs 87), and recovers the 24 lost 2024 mice. In group split, all sources perform similarly (~56–58%), confirming the generalization bottleneck is the model architecture, not the data source.

Recommendations

Use external data as the primary data source — it has correct genotyping and the most complete coverage.

To close the gap with legacy and improve true generalization:

  • Reduce reliance on mother_gen — this feature is ~50% of model importance but only ~50% predictive. Explore acoustic-only feature sets
  • Address class imbalance: oversampling HET, SMOTE, or scale_pos_weight in XGBoost
  • Collect more HET samples — currently only 27 HET mice across all sources; more disease examples are needed
  • Improve acoustic features — syllable features contribute only 1–3% each; temporal and spectral feature engineering could increase their discriminative power
