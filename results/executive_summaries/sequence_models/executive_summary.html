Neural Networks Executive Summary — Sequence Models

BiLSTM vs 1D-CNN vs Transformer  |  6 Configurations  |  May 2026

Objective

Evaluate whether sequence-based deep learning models (BiLSTM, 1D-CNN, Transformer) can classify mouse pups as Wild-Type (WT) or ASD-model (HET) using the temporal ordering of ultrasonic vocalizations (USVs). This complements the existing tabular models (XGBoost, TabPFN) that use aggregated per-recording features and lose temporal information.

Approach

Data Representation

Instead of aggregating syllable features into a single vector per recording, we preserve the ordered sequence of syllables within each mouse-day-session. Each session contains a median of 236 syllables (442 sessions total from 119 mice: 91 WT, 28 HT).

Per-syllable features (14 dimensions):

  • Continuous: Start Point (Hz), End Point (Hz), Duration, ISI time
  • Syllable type: Learned embedding (11 types → 8 dimensions)
  • Binary flags: Noise indicator, Recording boundary marker

Static metadata (mother genotype, sex, day, session) is concatenated to the model output before classification.

Models

ModelTypeParametersHow It Reads the Sequence
BiLSTM Recurrent (LSTM) 148,953 Step-by-step with memory, reads forward and backward
1D-CNN Convolutional 86,041 Sliding window (size 3) detecting local patterns
Transformer Self-Attention 72,537 Every syllable attends to every other syllable simultaneously

Training Setup

  • Framework: PyTorch, CPU training
  • Max sequence length: 256 syllables (covers median session length)
  • Loss: BCEWithLogitsLoss with pos_weight for class balancing
  • Optimizer: Adam (lr=0.001) with ReduceLROnPlateau scheduler
  • Early stopping: Patience 15 epochs on validation AUC
  • Split: 60% train / 20% val / 20% test

Analysis

1. BiLSTM: High Accuracy, No Disease Detection

BiLSTM achieves the highest accuracy (73–76%) but fails to detect HT mice (0–3% HT recall). It effectively predicts “WT” for almost all samples. The high AUC (0.74–0.80) suggests the model's probabilities have some discriminative power, but the 0.5 decision threshold does not separate the classes. This is a classic case of majority-class bias despite class-weighted loss.

2. Transformer: Best HT Recall Among Sequence Models

The Transformer achieves 90% HT recall in random split and 76% in group split, matching XGBoost's disease detection capability. However, this comes at the cost of very low accuracy (39–57%) and many false positives (precision 27–37%). The Transformer's self-attention mechanism appears to capture temporal patterns relevant to ASD detection.

3. 1D-CNN: Balanced but Modest Performance

The 1D-CNN provides the most balanced tradeoff between HT and WT detection, with 52–72% HT recall and reasonable WT F1. It is the fastest model to train (<1 min) but achieves lower overall discrimination (AUC 0.55–0.65).

4. Group Split Degrades All Models

All three models show performance degradation under group-aware splitting, confirming that random splits allow mouse-specific information leakage. The Transformer degrades least in terms of HT recall (90% → 76%).

5. Limited Data Is the Primary Bottleneck

With only 442 sessions from 119 mice (28 HT), the deep learning models are severely data-limited. The tabular pipeline benefits from 13,081 recording-level samples. Collecting more data from HT mice would likely improve sequence model performance significantly.

Conclusions

Sequence Models Show Promise for Disease Detection

The Transformer achieves 76–90% HT recall, demonstrating that temporal patterns in syllable sequences carry diagnostic signal for ASD classification. This validates the hypothesis that the “syntax” of mouse vocalizations contains information lost by the tabular aggregation pipeline.

Not Yet Ready to Replace Tabular Models

The sequence models suffer from low precision (many false positives) and are limited by small sample size (442 sessions vs 13K recordings). XGBoost with class balancing remains the better production classifier until more data is available.

Recommendations

Keep XGBoost as the primary classifier. Use sequence models as complementary analysis.

  • Best sequence model: Transformer with group split (56.7% acc, 76% HT recall, best balance of detection and precision).
  • Priority improvement: Collect more HT mouse data. The 28 HT mice are insufficient for deep learning.
  • Ensemble approach: Combining XGBoost's precision with the Transformer's sensitivity could yield a better balanced classifier.
  • GPU training: Would enable larger models, longer sequences (512+), and hyperparameter search.
  • Data augmentation: Time-domain augmentations (jitter, crop, reverse) could increase effective training size.

Appendix A — Data Pipeline

Source Data

The raw data comes from outputs/external/segmentation_classification_all_data.xlsx — a file containing 125,576 rows, one per detected syllable (USV call) across all mice, days, sessions, and recordings.

How the Data Is Produced

  1. Audio recording: Mouse pups are recorded in controlled sessions (specific day + session number). Each session produces multiple short WAV files, each called a “recording”.
  2. Segmentation: The preprocessing pipeline (src/preprocessing/) detects individual syllables (USV calls) in each WAV file, extracting start/end times, frequencies, and duration.
  3. Classification: A CNN classifier assigns each syllable a type (0–10: Complex, Frequency steps, Upward, Flat, Chevron, Short, etc.).
  4. Enrichment: Additional columns are computed: ISI (inter-syllable interval), syllable order within recording, noise flag, complexity level, and genotype encoding.
  5. Aggregation into Excel: All enriched syllable data is concatenated into the single Excel file used by this pipeline.

Appendix B — How to Run

Prerequisites

pip install "torch>=2.0.0"

All other dependencies (pandas, sklearn, matplotlib, seaborn) are already in requirements.txt.

Running a Single Model

# BiLSTM with group-aware split (recommended)
python src/classification/neural_networks/sequence_pipeline.py --model bilstm --independent

# 1D-CNN with random split
python src/classification/neural_networks/sequence_pipeline.py --model cnn1d

# Transformer with group split
python src/classification/neural_networks/sequence_pipeline.py --model transformer --independent

# All models × both split modes
for model in bilstm cnn1d transformer; do
  python src/classification/neural_networks/sequence_pipeline.py --model $model --epochs 50
  python src/classification/neural_networks/sequence_pipeline.py --model $model --independent --epochs 50
done

Appendix D — Feature Details

Per-Syllable Features (14 dimensions per timestep)

FeatureTypeDimsDescription
Start Point (Hz)Continuous1Frequency at the start of the syllable (standardized)
End Point (Hz)Continuous1Frequency at the end of the syllable (standardized)
Duration (time)Continuous1Syllable duration in seconds, clipped to [0, 1] (standardized)
ISI_timeContinuous1Inter-syllable interval (time since previous syllable), clipped to [0, 10], 0 for first syllable in recording (standardized)
Syllable typeEmbedding8Learned embedding from syllable class (0–10: Complex, Freq steps, Composite, Two syllables, Upward, Flat, Harmonic, Downward, Chevron, Short, Undefined)
NoiseBinary11 if Start Hz = End Hz (indicates noise, not a true vocalization)
Recording boundaryBinary11 at the first syllable of each recording within the session. Signals that the ISI value here is synthetic (filled with 0) because there is no preceding syllable in this recording

Static Metadata (4 dimensions, appended to model output)

FeatureDescription
Mother Genotype (binary)1 if mother is WT, 0 if HT
Sex1 if male, 0 if female
DayAge of pup in days (4, 6, 8, 10, or 12)
SessionRecording session number (0, 1, or 2)

Target Variable

Offspring Genotype (binary): 1 = WT (Wild-Type), 0 = HT (Heterozygous / ASD-model). This is what the model predicts. In this pipeline, the “positive class” is WT and the “disease class” is HT (class 0).
