Central Executive Summary — All Models & Configurations

XGBoost vs TabPFN  |  8 Configurations + 4 Per-Strain  |  May 2026

Objective

Classify mouse pups as Wild-Type (WT) or ASD-model (HET) based on ultrasonic vocalization (USV) features. This document compares all model × configuration combinations and explains what each configuration means.

External Data Is the Preferred Dataset

The --external flag uses the externally-validated dataset with correct individual genotyping. The pipeline-aggregated data (all_data.csv) had genotype labeling errors — all pups of HET mothers were labeled HET, when ~50% are actually WT. Always use --external for training runs.

Directory naming convention: results/tabular_models/<model>[_subject_eval_dependent|_subject_eval_independent][_external]/
_subject_eval_dependent = random split (subject may appear in multiple sets); _subject_eval_independent = group split by subject (--group-split / --independent). Example: results/tabular_models/tabpfn_subject_eval_dependent_external/.

Analysis

1. XGBoost Detects Disease Far Better (HET Recall)

The most critical metric for disease screening is HET recall — how many sick mice the model actually catches. XGBoost dramatically outperforms TabPFN:

ConfigurationXGBoostTabPFNGap
Base (random)97%27%−70%
Group split70%52%−18%
External (random)97%15%−82%
External + group90%17%−73%

XGBoost’s compute_sample_weight(balanced) and scale_pos_weight=0.8 actively push the model to detect HET mice. TabPFN has no class balancing mechanism and defaults to predicting the majority class (WT).

2. TabPFN’s Higher Accuracy Is Misleading

TabPFN wins on overall accuracy in 3 of 4 configurations, but this reflects the class imbalance (70–75% WT). Predicting “WT” for everything would yield ~72% accuracy. TabPFN is effectively a near-majority-class predictor with limited disease detection ability.

3. Impact of Group-Aware Splitting

Both models degrade under group split, confirming some information leaks between splits when the same mouse appears in train and test sets:

XGBoost: Random → GroupTabPFN: Random → Group
Pipeline: Accuracy drop−8.3%−19.7%
External: Accuracy drop−14.6%−10.6%

Group split is the more realistic evaluation. The drops are expected and highlight that the random-split numbers are optimistic.

4. Impact of External Data

Adding external data (9,515 → 13,081 samples) generally improves accuracy for both models. For XGBoost with random split, accuracy goes from 66.6% to 70.7% (+4.1%). External data helps most with group split, where XGBoost goes from 58.3% to 56.1% (slight drop, but HET recall improves from 70% to 90%).

5. Why TabPFN Fails on HET Detection

  • No class balancing: TabPFN v1 does not accept sample_weight. With 70–76% WT data, it learns to predict the majority class.
  • Prior mismatch: Pre-trained on synthetic balanced datasets; real-world class imbalance (24–30% HET) is outside its training distribution.
  • Weak signal amplification: Discriminative features contribute only 1–3% each. XGBoost’s boosting amplifies these better than TabPFN’s attention.

Per-Strain Observations

  • Strain 1 (newer cohorts, 70 mice): high HET recall in both evaluations (97–98%), consistent with the combined external runs. Subject-independent accuracy drops ~6 percentage points vs dependent.
  • Strain 2 (older cohorts, 50 mice): dependent performance is slightly better than strain 1 on test accuracy (75.5% vs 74.5%). Conclusions

TabPFN Cannot Detect Disease

Despite higher overall accuracy in most configurations, TabPFN misses 73–85% of HET (ASD-model) mice in random split. For a disease screening task, this makes it unsuitable as a standalone classifier. The accuracy improvement reflects majority-class bias, not better detection.

XGBoost Remains the Best Option

XGBoost with class balancing detects 90–97% of HET mice (random split) and 70–90% (group split), making it the only viable model for ASD screening. Its lower overall accuracy reflects the deliberate tradeoff: catching disease cases matters more than avoiding false alarms.

Recommendations

Keep XGBoost as the primary classifier.

  • Best production config: XGBoost + external data + group split (56.1% accuracy, but 90% HET recall — catches nearly all sick mice).
  • TabPFN v2 (Python 3.9+) may handle imbalance better — worth revisiting when upgrading the Python environment.
  • CatBoost / LightGBM support class weighting natively and are natural next candidates.
  • Ensemble approach: combining XGBoost’s sensitivity with TabPFN’s specificity could yield a better balanced classifier.
  • Improve acoustic features: mother_gen dominates (~57% importance). Stronger syllable-level features would benefit any model.
