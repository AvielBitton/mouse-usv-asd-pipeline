Neural Networks Executive Summary — Sequence Models (Baseline)

BiLSTM vs 1D-CNN vs Transformer  |  6 Configurations  |  --baseline dataset  |  June 2026

Objective

Evaluate whether sequence-based deep learning models (BiLSTM, 1D-CNN, Transformer) can classify mouse pups as Wild-Type (WT) or ASD-model (HT) from the temporal ordering of ultrasonic vocalizations (USVs), on the official --baseline dataset. This complements the tabular models (XGBoost, TabPFN) that use aggregated per-recording features and discard ordering. See docs/NEURAL_NETWORK_BASELINE.md.

Approach

Data Representation

Instead of aggregating syllables into one feature vector per recording, we preserve the ordered sequence of syllables within each mouse-day-session (408 sessions in the baseline split; median ~236 syllables/session). Each syllable is a 14-dimensional vector:

  • Continuous (4): Start Point (Hz), End Point (Hz), Duration, ISI time
  • Syllable type (8): learned embedding (11 types → 8 dims)
  • Binary flags (2): Noise indicator, Recording-boundary marker

Static metadata (mother genotype, sex, day, session) is concatenated to the encoder output before classification.

Training Setup

  • Framework: PyTorch, CPU training
  • Max sequence length: 256 syllables
  • Loss: BCEWithLogitsLoss with pos_weight for class balancing
  • Optimizer: Adam (lr=0.001) with ReduceLROnPlateau
  • Early stopping: patience 15 on validation AUC; seed 100
  • Split: 60% train / 20% val / 20% test

Analysis

Across the six configurations, the highest HT (disease) recall is BiLSTM (dependent) at 100.0% (test accuracy 23.2%, AUC 0.790).

Dependent → Independent (subject-level) split: BiLSTM: 23.2% → 45.6% test accuracy; 1D-CNN: 50.0% → 63.3% test accuracy; Transformer: 65.9% → 54.4% test accuracy. The independent split removes subject leakage and is the honest generalization estimate.

Appendix — Reproduce & Read

Commands (CPU)

for m in bilstm cnn1d transformer; do
  .venv/bin/python src/classification/neural_networks/sequence_pipeline.py --model $m --baseline

done
.venv/bin/python scripts/generate_nn_executive_summary.py --strict

Per-run output files

  • results.json — metrics (accuracy, AUC, per-class precision/recall/F1)
  • plots/ — training_curves, confusion_matrix(+counts), roc_curve
  • model/<model>_best.pt + scaler.pkl
  • logs/out.txt — full training log

Target variable

Binary genotype, encoded 0 = WT, 1 = HT (current pipeline). HT metrics therefore live under classification_report["1.0"] and are the minority class. (Legacy pre-baseline runs used the inverted encoding; this report detects HT by minority support and cross-checks the printed HT (N) index, so it is correct regardless.)
