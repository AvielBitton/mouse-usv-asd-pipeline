# Mouse USV ASD Pipeline

This project processes ultrasonic vocalizations (USVs) of mouse pups and classifies each pup as **healthy** or **ASD-related**, following the workflow used in the original research.

The system covers the full pipeline: loading recordings and metadata, extracting syllables, running segmentation, generating acoustic features, and performing ASD classification.

## Pipeline Overview

### Step 0: Generate Metadata (New)

Before running the main pipeline, you need to generate metadata files from your WAV recordings:

**Option A: Local Directory**
```bash
python generate_metadata.py --local --source-dir dumps
```

**Option B: Google Drive**
```bash
python generate_metadata.py --drive --drive-folder-url "https://drive.google.com/drive/folders/YOUR_FOLDER_ID"
```

**What it does:**
- Scans WAV files in local directories or Google Drive folders
- Extracts metadata from folder structure (year, mother, name, day, session, channel)
- Loads sex information from Excel tables in year folders
- Generates `Metadata Recording Mapping ({year}).xlsx` under `metadata/mapping/`
- Skips years that already have metadata files (incremental updates)

**📖 For detailed instructions:** See `GENERATE_METADATA_README.md`

**☁️ For Google Drive setup:** See `GOOGLE_DRIVE_SETUP.md`

### Google Drive Integration

The `generate_metadata.py` script supports scanning WAV files directly from Google Drive folders, which is useful when:
- Data is stored in Google Drive and not available locally
- Multiple team members need to access the same data
- You want to avoid downloading large amounts of data locally

**How it works:**
1. **Authentication:** Uses OAuth 2.0 to authenticate with Google Drive API
   - Requires `credentials.json` file (see `GOOGLE_DRIVE_SETUP.md`)
   - First run opens browser for authentication
   - Creates `token.json` for subsequent runs (user-specific, don't share)

2. **Scanning:** Recursively scans Google Drive folders for WAV files
   - Supports folder ID or URL input
   - Finds year folders (e.g., 2015, 2018, 2022)
   - Extracts metadata from folder structure
   - Downloads Excel files for sex data extraction

3. **Team Collaboration:**
   - Share `credentials.json` with team members
   - Each person creates their own `token.json` (one-time authentication)
   - Add team members as "Test users" in Google Cloud Console
   - Share Google Drive folder with team members

**📖 Detailed setup guide:** See `GOOGLE_DRIVE_SETUP.md` for step-by-step instructions

### Main Pipeline

1. **Load Metadata**  
   Reads the metadata file containing: pup name, session, day, start/end frequencies, and other fields.

2. **Load Audio Files**  
   Imports the WAV recordings for each session.

3. **Segmentation**  
   Extracts syllables (USVs) from raw audio.  
   **Important:** The original segmentation script from the lab is missing and must be obtained to reproduce the results fully.

4. **Classification**  
   Uses the original ASD classifier to categorize each syllable type (0–10).

5. **Column Enrichment**  
   Adds derived columns to the segmentation Excel: row index, year, genotype binary flags, syllable order within recording, noise indicator, supplement flags, syllable type English labels, and complexity levels. See `docs/Running_the_Pipeline.md` for the full column list.

6. **Feature Extraction**  
   Derives acoustic and spectral features from each syllable.

7. **Aggregation**  
   Combines all per-file outputs into `all_data.xlsx` and `all_data.csv`.
